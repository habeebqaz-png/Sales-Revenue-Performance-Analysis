# Sales Revenue Performance Analysis

## Project Overview
This project explores sales revenue data through an interactive dashboard designed to evaluate product performance, sales representative contributions and revenue trends across different locations.

## Project Objectives
- Identify the top and bottom five sales representatives by revenue.
- Analyse the highest and lowest revenue-generating products.
- Examine product contributions to total revenue.
- Compare sales performance across locations.
- Track monthly revenue trends.
- Enable interactive analysis using product category filters.

## Tools Used
- Microsoft Excel
- Data Analysis
- Data Visualisation

## Key Dashboard Features
- Top 5 and Bottom 5 Sales Representatives by Revenue.
- Top 5 and Bottom 5 Products by Revenue.
- Product Revenue Contribution.
- Monthly Revenue Trend.
- Location-based Sales Comparisons.
- Interactive Product Category Filter.

## Conclusion
This project demonstrates the use of data analysis and visualisation to monitor revenue performance, identify high- and low-performing areas, and support business decision-making.
